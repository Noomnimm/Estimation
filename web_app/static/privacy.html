นโยบายความเป็นส่วนตัว

Material Calculator · ปรับปรุงล่าสุด 7 ตุลาคม 2569

นโยบายนี้อธิบายข้อมูลที่ Material Calculator ใช้เมื่อท่านคำนวณ บันทึก หรือจัดการข้อมูลงานบนเว็บไซต์ C3EAP Estimation

ข้อมูลที่เราใช้

  • ข้อมูลบัญชี Google: ชื่อและอีเมลที่ได้รับจาก Google Sign-In เพื่อยืนยันตัวตนและผูกงาน Cloud กับบัญชีผู้ใช้
  • ข้อมูลงาน: ชื่องาน เลขผัง แผนก รายการวัสดุ ปริมาณ ผลคำนวณ และข้อมูลหน้าของงานที่ท่านบันทึก
  • คำขอแก้ไข BaseData: ชื่อ รหัสพนักงาน สังกัด รายการวัสดุ หมายเหตุ และรูปประกอบที่ผู้ใช้ส่งโดยสมัครใจ เพื่อให้ผู้ดูแลตรวจสอบและอนุมัติ
  • ข้อมูลในอุปกรณ์: งานที่บันทึกในเครื่องจะอยู่ในเบราว์เซอร์หรือไฟล์บนอุปกรณ์ของท่าน จนกว่าท่านจะลบข้อมูลนั้นเอง

การใช้ Google user data และ Google Drive

เราใช้ชื่อและอีเมลจาก Google เพื่อเข้าสู่ระบบและแสดงเจ้าของงาน ฟังก์ชัน Cloud ใช้ Google Sheets เก็บข้อมูลรายการงานและข้อมูล BaseData บางส่วน และใช้ Google Drive เก็บหรือเปิดไฟล์ JSON ของงานและรูปประกอบหัวเสาในโฟลเดอร์ที่ผู้ดูแลกำหนด

สิทธิ์ Drive ที่แอปขอในหน้าความยินยอมปัจจุบันคือสิทธิ์ Drive แบบกว้าง (drive) แม้การทำงานปัจจุบันของแอปจะใช้โฟลเดอร์ที่กำหนดและไฟล์ที่เกี่ยวข้องกับงานในระบบเป็นหลัก โปรดตรวจสอบและยินยอมเฉพาะเมื่อท่านเข้าใจขอบเขตสิทธิ์นี้

การจัดเก็บและผู้ให้บริการ

ข้อมูล Cloud ถูกจัดเก็บใน Google Sheets และ Google Drive ที่ผู้ดูแลระบบกำหนด เว็บไซต์ทำงานบนบริการโฮสต์ Render ส่วน Google ให้บริการยืนยันตัวตนและพื้นที่จัดเก็บที่แอปเชื่อมต่อ ผู้ดูแลที่ได้รับอนุญาตอาจเข้าถึงข้อมูลที่จำเป็นต่อการดูแลระบบและตรวจคำขอ BaseData

เราไม่ขาย Google user data ข้อมูลจะถูกใช้เพื่อให้บริการคำนวณ บันทึก เปิดงาน และดูแล BaseData ตามที่อธิบายไว้ในนโยบายนี้เท่านั้น

ระยะเวลาจัดเก็บและการลบ

งาน Cloud จะอยู่ในระบบจนกว่าผู้ใช้จะลบ งานที่ลบจากรายการปกติจะถูกย้ายไปถังขยะและยังอาจกู้คืนได้ จนกว่าจะมีการลบถาวรโดยผู้ใช้หรือผู้ดูแล การลบถาวรจะลบระเบียนงานและไฟล์ JSON ที่เกี่ยวข้องจากพื้นที่จัดเก็บที่ระบบจัดการ ทั้งนี้ผู้ให้บริการที่เกี่ยวข้องอาจมีการสำรองหรือเก็บข้อมูลตามนโยบายของตน

คำขอแก้ไข BaseData อาจถูกเก็บไว้ใน Google Sheets เพื่อให้ผู้ดูแลตรวจสอบ ติดตามสถานะ และดูแลข้อมูลฐาน ผู้ใช้สามารถติดต่อผู้ดูแลเพื่อสอบถาม แก้ไข หรือลบข้อมูลที่เกี่ยวข้องได้

ความปลอดภัยและสิทธิ์การเข้าถึง

เราใช้การเข้าสู่ระบบและการกำหนดสิทธิ์เพื่อจำกัดการเข้าถึงฟังก์ชัน Cloud และข้อมูลที่เกี่ยวข้อง อย่างไรก็ตาม การส่งข้อมูลผ่านอินเทอร์เน็ตไม่มีวิธีใดรับประกันความปลอดภัยได้สมบูรณ์ โปรดอย่าส่งข้อมูลส่วนบุคคลที่ไม่จำเป็นผ่านระบบ

ท่านสามารถถอนสิทธิ์ที่มอบให้แอปได้จากการตั้งค่าบัญชี Google การถอนสิทธิ์อาจทำให้การบันทึกหรือเปิดงาน Cloud ใช้งานไม่ได้ แต่ไม่ได้ลบข้อมูลที่บันทึกไว้แล้วโดยอัตโนมัติ
