ข้อกำหนดการใช้งาน

Estimation · ปรับปรุงล่าสุด 7 ตุลาคม 2569

เมื่อเข้าใช้ Estimation บน C3EAP Estimation ถือว่าท่านยอมรับข้อกำหนดต่อไปนี้ หากไม่ยอมรับ โปรดหยุดใช้บริการ

วัตถุประสงค์และการใช้งาน

ระบบจัดทำขึ้นเพื่อช่วยคำนวณและจัดเตรียมรายการวัสดุจาก BaseData/ชุด SET รวมถึงบันทึกและเปิดข้อมูลงาน ผู้ใช้ต้องใช้งานตามสิทธิ์ที่ได้รับและไม่พยายามเข้าถึง แก้ไข หรือลบข้อมูลของผู้อื่นโดยไม่ได้รับอนุญาต

บัญชีและข้อมูลที่ส่ง

ผู้ใช้ต้องใช้บัญชี Google ที่ได้รับอนุญาตสำหรับฟังก์ชัน Cloud และรับผิดชอบต่อข้อมูลที่บันทึกหรือส่งให้ผู้ดูแล ผู้ส่งคำขอแก้ไข BaseData รับรองว่ามีสิทธิ์ส่งข้อมูลและรูปประกอบดังกล่าว

ความถูกต้องของผลลัพธ์

ผลคำนวณขึ้นอยู่กับ BaseData สูตร และข้อมูลที่ผู้ใช้ป้อน ระบบเป็นเครื่องมือช่วยจัดทำประมาณการ ไม่ทดแทนการตรวจสอบแบบ วิศวกรรม มาตรฐาน หรือการอนุมัติตามขั้นตอนของหน่วยงาน ผู้ใช้ต้องตรวจสอบรายการ รหัสพัสดุ ปริมาณ และความเหมาะสมก่อนนำไปใช้หรือสั่งซื้อ

การบันทึก Cloud และบริการภายนอก

ฟังก์ชัน Cloud เชื่อมต่อ Google Sign-In, Google Sheets และ Google Drive เพื่อยืนยันตัวตนและจัดเก็บข้อมูลตามนโยบายความเป็นส่วนตัว การใช้งานบริการเหล่านั้นอยู่ภายใต้ข้อกำหนดของผู้ให้บริการด้วย ผู้ใช้ควรตรวจสอบหน้าความยินยอมของ Google ก่อนอนุญาตสิทธิ์

การลบและความพร้อมใช้งาน

งาน Cloud ที่สั่งลบอาจย้ายไปถังขยะก่อนลบถาวร ผู้ใช้ควรตรวจสอบและลบถาวรเมื่อไม่ต้องการเก็บอีก ระบบอาจหยุดให้บริการชั่วคราวเพื่อบำรุงรักษา แก้ไขปัญหา หรือปรับปรุงความปลอดภัย และไม่รับประกันความพร้อมใช้งานต่อเนื่องโดยไม่มีการหยุดชะงัก
